# Azure DevOps CI/CD Demo

## Overview
This project demonstrates a complete CI/CD pipeline using Azure DevOps.

## Technologies
- Node.js
- Express
- Git
- GitHub
- Azure DevOps
- Azure App Service

## CI/CD Flow

Developer->GitHub->Azure DevOps Pipeline->Build->Deploy->Azure App Service

## Features
- Git branching
- YAML pipeline
- Automated deployment
- Azure Service Connection
